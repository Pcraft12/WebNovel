📖 About Novel Reader

Your ultimate destination for reading web novels from multiple sources

🌟 Features

  • ✅ Multi-Source Support: Search and read from 5+ novel websites
  • ✅ Auto-Translation: Translate Chinese novels to English using Google Translate
  • ✅ Text-to-Speech: Listen to your novels with customizable TTS voices
  • ✅ Favourites: Save your favorite novels for quick access
  • ✅ Clean UI: Ad-free reading experience with modern design
  • ✅ Smart Extraction: Intelligent chapter content extraction

📚 Supported Sources

  • • IXDZS8 (ixdzs8.com) - Hot daily updates
  • • Shuhaige (m.shuhaige.net) - Extensive library
  • • Biquge (biquge.company) - Classic layout
  • • TTKan (ttkan.co) - Modern UI with rankings
  • • XBiquge (xbiquge.info) - Weekly top novels

⚙️ How to Use

  1. Search: Use the search page to find novels across all sources
  2. Browse: Check the sources page for latest updates from each site
  3. Read: Click on any novel to start reading chapters
  4. TTS: Use the text-to-speech panel to listen to chapters
  5. Translate: Enable auto-translation in settings for English content
  6. Favourite: Star novels to save them in your favourites

🔧 Settings

Customize your reading experience:

  • • Translation toggle (on/off)
  • • TTS voice, speed, and pitch
  • • Font size and line height
  • • Theme selection (Light/Dark/Sepia)
  • • Auto-scroll and highlight options
